# 화이트펜슬 환불 계산기

신규 환불규정(비례정산 + 위약금 10%) 기준 환불 금액 계산기.
`index.html` 파일 하나로 동작하며, 계산은 전부 브라우저 안에서 끝난다 — 서버도 빌드도 필요 없다.

- **GitHub Pages**: <https://whitepencil-studycafe.github.io/refund-calculator/>
- **서버 PC**: <https://whitepencil.shop/refund> (같은 파일을 `server-pc/refund_calculator.html` 로 서빙)

## 환불 기준

소비자의 변심 또는 상황변화로 인한 환불.

| 구분 | 기준 |
|---|---|
| 환불기한 | 유효기간 내에만 가능 |
| 이용개시일 이전 | 결제금액에서 위약금 10% 제외한 금액 환불 |
| 이용개시일 이후 (시간권) | 결제금액 − [결제금액 × (사용시간 / 계약상 이용시간)] − 위약금 10% |
| 이용개시일 이후 (기간권) | 결제금액 − [결제금액 × (사용기간 / 계약상 이용기간)] − 위약금 10% |

- 당일권은 환불 불가.
- 시간권·기간권도 유효기간이 지나면 환불 불가.
- 스터디룸은 예약 당일 취소 및 환불 불가.
- 시간권의 "남은 사용시간 vs 남은 유효기간" 비교는 **각각의 잔여비율**로 한다.

      시간 잔여비율     = 잔여시간 / 계약상 이용시간
      유효기간 잔여비율 = 남은 유효기간 / 전체 유효기간
      환불 대상 비율    = 둘 중 낮은 쪽

  시간이 남아도 쓸 날이 없으면 그만큼밖에 못 쓰기 때문이다.
  예) 50시간·유효기간 60일에서 잔여 40시간(80%)인데 유효기간이 1일(1.7%) 남았다면 → **1.7%만 환불 대상**
  (80,000원 × 1.7% = 1,333원에서 위약금 8,000원을 빼면 음수라 환불 0원)

### 스터디룸

세 갈래로 나뉜다.

| 결제 형태 | 계산기에서 고를 것 | 기준 |
|---|---|---|
| 시간 단위 예약 (2인실 1시간 5,000원) | 스터디룸 예약 | 예약일 당일·이후면 환불 불가, 그 전이면 결제금액의 90% |
| 시간권 (2인실 20시간 90,000원) | 스터디룸 시간권 | 시간권 규정 그대로 (비례정산 + 위약금 10%) |
| 당일권 | 당일권 | 환불 불가 |

### 시간권 연장(재구매)

연장 시 기존 잔여시간은 신규 이용권에 합산되어 이용은 가능하지만, 환불은 **신규 결제금액**과
**신규 결제 이후 사용시간**만으로 계산한다. 기존 유효기간이 1일만 남았어도 시간은 합산되며
유효기간은 신규 이용권 기준으로 새로 시작한다. 기존 유효기간이 지난 잔여시간은 환불되지 않는다.

## 기본값

버튼으로 채워지는 값일 뿐, 모든 항목은 직접 수정할 수 있다.

| 상품 | 결제금액 | 유효기간 |
|---|---|---|
| 시간권 50시간 | 80,000원 | 60일 |
| 시간권 100시간 | 140,000원 | 120일 |
| 시간권 200시간 | 250,000원 | 180일 |
| 기간권 2주권 | 100,000원 | — |
| 기간권 4주권 | 160,000원 | — |
| 스터디룸 시간권 2인실 20시간 | 90,000원 | 60일 |
| 스터디룸 예약 2인실 | 시간당 5,000원 | — |

스터디룸 시간권 30시간과 기간권 8·12·48주권은 금액이 확정되지 않아 시간·기간만 채우고
금액은 직접 입력한다.

## 로고

`logo.jpg` 를 같은 폴더에 둔다. 서버(`/refund`)에서는 `/static/logo.jpg` 를 먼저 찾고,
없으면 같은 폴더의 `logo.jpg` 로 넘어간다. 둘 다 없으면 로고 자리를 비운다.

## 환불 접수 버튼 (점검 중)

「환불 접수하기」는 지금 **점검 안내 팝업만 띄운다.** 규정이 바뀌었는데 접수 폼이 아직
예전 그대로라, 열어두면 규정과 안 맞는 신청이 들어오기 때문이다.

재개할 때는 `index.html` 의 `id="apply"` 버튼을 주석에 적어둔 폼 주소로 되돌리면 된다.
링크(`<a>`)가 아니라 버튼으로 둔 이유는, 링크면 새 탭으로 열기나 주소 복사로 점검 안내를
지나칠 수 있어서다.
